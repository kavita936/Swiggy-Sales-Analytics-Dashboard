#  Swiggy Sales Dashboard — Excel

An interactive Excel dashboard analyzing Swiggy's sales performance across cities, states, restaurants, and food categories.

![Swiggy Dashboard Preview](Screenshot%202026-04-18%20091043.png)

---

##  Overview

This dashboard provides a comprehensive view of Swiggy's order and revenue data, enabling quick insights into sales trends, top-performing cities, restaurants, and food types — all from within Microsoft Excel.

##  Dashboard Features

- **Monthly Sales Trend** — Line chart tracking revenue from January through August
- **Daily Sales Trend** — Bar chart showing sales patterns across days of the week (Sun–Sat)
- **Top 5 Cities by Sales** — Horizontal bar chart ranking New Delhi, Mumbai, Lucknow, Hyderabad, and Bengaluru
- **Top 5 Restaurants by State** — Comparative bar chart for Burger King, Domino's Pizza, KFC, McDonald's, and Pizza Hut
- **Sales by Food Type** — Donut chart showing Veg vs Non-Veg split (Non-Veg: 65.83%, 36% | Veg: 34.15%, 64%)
- **Sales by State** — Choropleth map of India with state-level sales intensity

---

##  Interactive Filters

- **Month Slicer** — Filter data by month (Jan–Dec)
- **Restaurant Name Slicer** — Drill down into individual restaurant performance
- **Category Slicer** — Filter by food category (e.g., HK Burgers, High Protein, Holi Special, etc.)

---

##  Tools Used

- **Microsoft Excel** — Pivot Tables, Pivot Charts, Slicers, Power Query
- **Chart Types** — Line, Bar, Donut, Choropleth Map
- **Design** — Custom Swiggy-themed branding with orange color palette
